# C# File Handling 📂

A collection of C# practice projects focused on file handling, directory management, JSON serialization, and deserialization using .NET.

## 📌 Projects

### 1. JSON Serialization & File Handling

A WPF application that converts user object data into JSON format and saves it to a text file.

**Concepts Covered:**

* JSON Serialization using `JsonConvert.SerializeObject()`
* File Handling using `File.WriteAllText()`
* File Existence Checking using `File.Exists()`
* Directory Creation using `Directory.CreateDirectory()`
* File Path Handling using `Path.Combine()`
* Conditional Statements (`if-else`)

### 2. File & Directory Basics

A practice project covering fundamental file and directory operations in C#.

**Concepts Covered:**

* File Operations
* Directory Management
* File Path Handling
* Checking File Existence
* Creating Directories
* Writing Data to Files

### 3. JSON Deserialization Login

A WPF login application that reads saved user data from a text file and validates the entered username and password.

**Concepts Covered:**

* JSON Deserialization using `JsonConvert.DeserializeObject<T>()`
* Reading File Content using `File.ReadAllText()`
* File Existence Checking using `File.Exists()`
* Directory Management
* Username and Password Validation
* Conditional Statements (`if-else`)
* WPF Event Handling

## 🛠️ Technologies Used

* **Language:** C#
* **Framework:** .NET / WPF
* **JSON Library:** Newtonsoft.Json
* **UI Design:** XAML
* **IDE:** Visual Studio

## 🎯 Learning Objectives

* Understand file handling operations in C#.
* Practice creating and managing directories.
* Learn how to serialize C# objects into JSON.
* Learn how to deserialize JSON data into C# objects.
* Understand how to read and write data using files.
* Improve programming logic through practical WPF applications.
